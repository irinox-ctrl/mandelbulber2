  BELANGRIJKE REGELS
───────────────────────────────────────────────────────────────────────────────

1. NA ELKE BRANCH WIJZIGING: make clean + qmake + make
   De Makefile is branch-afhankelijk!

2. BACKUP MAKEN VOOR GROTE WIJZIGINGEN
   ./BACKUP_MAKEN.sh "voor-gradient-opsplitsing"

3. COMMIT REGELMATIG OP WIP
   cd mandelbulber2
   git add -A
   git commit -m "WIP: korte omschrijving"

4. STABIEL ALLEEN AANPASSEN VOOR BUGFIXES
   Geen nieuwe features op de stabiele branch!

───────────────────────────────────────────────────────────────────────────────
  NOODGEVAL
───────────────────────────────────────────────────────────────────────────────

Als ALLES kapot is en je wilt helemaal opnieuw beginnen:

   ./HERSTELLEN.sh MASTER_BACKUP_20260510_131244.tar.gz
   cd mandelbulber2/build
   make clean && qmake ../qmake/mandelbulber.pro && make -j$(nproc)

Dit geeft je een schone, werkende repo met beide branches.
