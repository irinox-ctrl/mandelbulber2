💡 Critical Insights

The Fake Lights system has THREE color channels (color, color_2, color_3) each independently toggleable.
Orbit trap shapes are NOT just static geometries; 8 universal modifiers can warp any shape.
Shape blending allows mixing TWO different shapes with a smooth blend amount.
The Onion modifier turns solid shapes into hollow shells (fabs(dist) - thickness).
Positioning has 4 modes: World (0), Camera Relative (1), Target Relative (2), FractalCenter (3).
CPU implementation re-computes the fractal 4 times per light (center + 3 offsets) for normal estimation.
OpenCL V2 has a layer-based compositing system with blend modes (Normal, Add, Multiply, Screen, Overlay).
OpenCL V2 has clipping volumes (Sphere, Box, FractalDistance) with Inside/Outside/Border modes.
CRITICAL: C++ side lacks the sFakeLightsV2 struct and layered implementation found in OpenCL.
The 26 shapes include both primitives (sphere, cube) and fractals (Menger, Sierpinski, Apollonian, Koch).
