## 🎯 PROBLEEM EN OPLOSSING

### Het Probleem
Nieuwe implementaties in Mandelbulber zijn tijdsintensief:
- **260+ regels XML** handmatig editen voor UI
- **6-7 bestanden** aanmaken per formule
- **Parameter naming** errors → silent failures
- **GPU struct changes** → crashes/blue screens
- **TOTAAL: 2-4 uur per formule**

### De Oplossing
**4 nieuwe automation tools:**
1. **UI Generator** - Genereer UI files van parameters
2. **Formula Scaffold** - Genereer alle files in één keer
3. **Parameter Validator** - Check naming consistency
4. **GPU Struct Checker** - Voorkom crashes

**TIJDSBESPARING: 1-3 uur per implementatie!**

## 📦 TOOL 1: UI FILE GENERATOR

### Wat Doet Het?
Genereer Qt .ui XML files automatisch van simpele parameter definities.

**Tijdsbesparing:** 1-2 uur per formule

### Features
✅ Support voor alle parameter types:
  - CVector3 (x,y,z spinboxes)
  - CVector4 (x,y,z,w spinboxes)
  - double (single spinbox)
  - int (integer spinbox)
  - bool (checkbox)
  - enum (combobox)
  - color (color button)

✅ Automatische widget naming: `spinboxd3_formula_name_parameter_x`
✅ Consistent layout en spacing
✅ Custom widget declarations
✅ 260+ regels XML → 5 regels Python!

### Gebruik

**Quick Demo:**
```bash
cd ~/mandelbulber2_v2_experiment/dev_tools
```


**Programmatic Use:**
```python
from ui_generator import UIGenerator, Parameter, ParamType

generator = UIGenerator("transf_rotation", "T>Rotation")

parameters = [
    Parameter(
        name="rotation",
        type=ParamType.CVECTOR3,
        display_label="Rotation angles",
        default=(0.0, 0.0, 0.0),
        min_val=-360.0,
        max_val=360.0,
        tooltip="Rotation in degrees"
    ),
    Parameter(
        name="scale",
        type=ParamType.DOUBLE,
        display_label="Scale factor",
        default=1.0,
        min_val=0.001,
        max_val=100.0
    ),
    Parameter(
        name="enabled",
        type=ParamType.BOOL,
        display_label="Enable transform",
        default=True
    )
]

output_file = Path("generated_ui/transf_rotation.ui")
generator.generate(parameters, output_file)
```

## 🔧 TROUBLESHOOTING

### UI Generator Issues

**Problem:** Generated UI doesn't show in Mandelbulber
```bash
# Check file location
ls ../mandelbulber2/formula/ui/my_formula.ui

# Check naming convention
# Must match: formula internal name = UI filename
```

**Problem:** Widget not connecting to parameter
```bash
# Check widget name format:
# spinboxd3_formula_name_parameter_x  ← Must match!
# NOT: spinboxd3_parameter_x
```

### Formula Scaffold Issues

**Problem:** Enum ID conflict
```bash
# Check enum file manually:
```

